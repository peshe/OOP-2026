# Задача

## 1. Базов клас `MythicalBanana`

**Защитени данни-членове:**
- `char* name` — име на банана;
- `int power` — сила;
- `char* peel` — тип кора (напр. `"Golden"`, `"Crystal"`, `"Rotten"`).

**Изисквания:**
- Конструктор с параметри (със стойности по подразбиране), заделящ собствени копия на низовете.
- Конструктор за копиране, оператор за присвояване и деструктор (правилото на тройката).
- Достъпващи методи: `getName()`, `getPower()`, `getPeel()`.
- Виртуален метод `describe() const`.
- Виртуални методи `canFloat() const` (по подразбиране `false`).
- Виртуален метод `clone() const` за полиморфно дълбоко копиране.
- Виртуален деструктор.

## 2. Междинни класове `Floating` и `Enchanted`

И двата наследяват **виртуално** от `MythicalBanana`, което гарантира едно-единствено копие на базовата част при класове, наследяващи и двата — решението на диамантения проблем.

**`Floating`:** защитено поле `int height` — височина на реене; предефинира `describe()`, `canFloat()` (връща `true`) и `clone()`. Напишете и функция `getHeight()`, която да върне колко лети банана.

**`Enchanted`:** защитено поле `char* spell` — заклинание, със собствено управление на памет; предефинира `describe()` и `clone()`.

## 3. Производен клас `LegendaryBanana`

Наследява **едновременно** `Floating` и `Enchanted`. Виртуалната база `MythicalBanana` се инициализира **директно** от `LegendaryBanana`. Предефинира `describe()` и `clone()`; реещото поведение наследява от `Floating`.

## 4. Контейнер `BananaContainer`

Контейнер с **фиксиран размер** върху динамичен масив `MythicalBanana**`.

**Данни:** `MythicalBanana** bananas`, `int capacity`, `int count`.

**Операции:**
- Конструктор с капацитет (изключение при неположителен); забранено копиране; деструктор, освобождаващ всичко.
- `add` — **добавя** банан (изключение при пълен контейнер).
- `append` — **добавя в края** дълбоки копия (чрез `clone()`) на всички елементи от друг контейнер; изключение при недостатъчно място.
- `print` — **извежда** съдържанието.
- `find` — **търси по име**; връща първото съвпадение или `nullptr`.
- `findByPeel` — **търси по тип кора**; връща нов масив + брой чрез изходен параметър.
- `findByMinHeight` — **търси по височина**: връща реещите банани с височина **по-голяма** от подадена стойност; нов масив + брой.
- `remove` — **маха по име**, запазвайки подредбата.
- Помощни: `size`, `getCapacity`, `isFull`, `isEmpty`, `operator[]`.

## 5. Демонстрация (`main`)

Да се демонстрират всички операции: създаване, добавяне, препълване, извеждане, търсене по име, по кора и по височина, премахване и сливане чрез `append`.
