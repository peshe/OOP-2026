# Задача

## 1. Базов клас `MythicalCreature`

**Защитени данни-членове:**
- `char* name` — име на създанието;
- `int power` — сила;
- `char* blood` — тип кръв (напр. `"Fire"`, `"Ichor"`, `"Cold"`).

**Изисквания:**
- Конструктор с параметри (със стойности по подразбиране), заделящ собствени копия на низовете.
- Конструктор за копиране, оператор за присвояване и деструктор (правилото на тройката).
- Достъпващи методи: `getName()`, `getPower()`, `getBlood()`.
- Виртуален метод `describe() const`.
- Виртуални методи `canFly() const` (по подразбиране `false`).
- Чисто виртуален или виртуален метод `clone() const` за полиморфно дълбоко копиране.
- Виртуален деструктор.

## 2. Междинни класове `Flying` и `Magical`

**`Flying`:** защитено поле `int altitude`; предефинира `describe()`, `canFly()` (връща `true`) и `clone()`. Допълнително се дефинира `getAltitude()`, което определя колко високо може да лети.

**`Magical`:** защитено поле `char* spell` със собствено управление на памет; предефинира `describe()` и `clone()`.

## 3. Производен клас `Dragon`

Наследява **едновременно** `Flying` и `Magical`. Виртуалната база `MythicalCreature` се инициализира **директно** от `Dragon`. Предефинира `describe()` и `clone()`; летящото поведение наследява от `Flying`.

## 4. Контейнер `CreatureContainer`

Контейнер с **фиксиран размер**(25) върху динамичен масив `MythicalCreature**`.

**Данни:** `MythicalCreature** creatures`, `int capacity`, `int count`.

**Операции:**
- Конструктор с капацитет (изключение при неположителен); забранено копиране; деструктор, освобождаващ всичко.
- `add` — **добавя** създание (изключение при пълен контейнер).
- `append` — **добавя в края** копия (дълбоки, чрез `clone()`) на всички елементи от друг контейнер; изключение при недостатъчно място.
- `print` — **извежда** съдържанието.
- `find` — **търси по име**; връща първото съвпадение или `nullptr`.
- `findByBlood` — **търси по тип кръв**; връща нов масив + брой чрез изходен параметър.
- `findByMinAltitude` — **търси по височина**: връща летящите създания с височина **по-голяма** от подадена стойност; нов масив + брой.
- `remove` — **маха по име**, запазвайки подредбата.
- Помощни: `size`, `getCapacity`, `isFull`, `isEmpty`, `operator[]`.

## 5. Демонстрация (`main`)

Да се демонстрират всички операции: създаване, добавяне, препълване, извеждане, търсене по име, по кръв и по височина, премахване и сливане чрез `append`.
