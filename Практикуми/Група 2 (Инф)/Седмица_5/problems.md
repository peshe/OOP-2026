Шаблоните в C++ са механизъм за генерично програмиране: пишеш една версия на функция или клас и компилаторът генерира конкретни реализации за различни типове.

Идея:

- Една обща логика, много типове (int, double, string, собствени класове).
- Повторна употреба без дублиране на код.
- Проверки и оптимизация още на етап компилация.

Особености:
- Има шаблони за функции и за класове.
- Параметрите могат да са типове, стойности (non-type), или други шаблони.
- Инстанцирането става при използване.

Използване:
- Стандартната библиотека разчита силно на шаблони: vector, map, optional, algorithms.
- Подходящи са за контейнери, математически/utility функции и общи компоненти.
- Избягват runtime overhead в много случаи, защото типът е известен при компилация.

Накратко: templates дават гъвкавост + производителност, но при по-сложни случаи могат да доведат до по-трудни за четене грешки от компилатора.

Ето прост пример за шаблон на функция:
```cpp
#include <iostream>

template <typename T>
T maxValue(T a, T b) {
    return (a > b) ? a : b;
}

int main() {
    std::cout << maxValue(3, 7) << '\n';         // int -> 7
    std::cout << maxValue(2.5, 1.2) << '\n';     // double -> 2.5
    std::cout << maxValue('a', 'z') << '\n';     // char -> z
}
```
Идеята е, че maxValue е написана веднъж, а работи за различни типове, стига да поддържат сравнение с >.

### Задача 1

Напишете шаблонна функция swapValues, която разменя стойностите на две променливи.

Условия:
- Функцията да е шаблонна и да работи за различни типове.
- Да не използва std::swap.

Примерни тестове:
- a = 5, b = 10 -> след извикване: a = 10, b = 5
- x = 2.5, y = 7.1 -> след извикване: x = 7.1, y = 2.5
- c1 = 'A', c2 = 'Z' -> след извикване: c1 = 'Z', c2 = 'A'

### Задача 2
 Напишете шаблонна функция countGreater, която брои колко елемента в масив са по-големи от дадена стойност.

Условия:

- Функцията да е шаблонна по тип T.
- Да работи за int, double и char.
- Да не използва STL контейнери (работи с обикновен масив).
- Да връща броя на елементите, за които arr[i] > threshold.

Примерни тестове:
- arr = {1, 5, 2, 8, 3}, threshold = 3 -> резултат: 2
- arr = {1.1, 2.7, 0.5, 2.7}, threshold = 1.0 -> резултат: 3
- arr = {'a', 'd', 'b', 'z'}, threshold = 'c' -> резултат: 2

### Задача 3
„Мини статистика“ с шаблонни функции

Напишете 3 шаблонни функции за масив:
- sumArray - Връща сумата на всички елементи.
- averageArray - Връща средно аритметично като double.
- countInRange - Брои колко елемента са в интервала [minValue, maxValue].

Изисквания:
- Само шаблонни функции, без класове и без std::vector.
- Да работи с обикновени масиви и подаден размер.
- Да има проверка за празен масив при averageArray (например връщаш 0.0).
- Тествай с поне два типа: int и double.

Примерни тестове:
int: {1, 5, 3, 8, 2}
sum = 19, average = 3.8, countInRange(2, 5) = 3

double: {1.5, 2.0, 4.5, 3.0}
sum = 11.0, average = 2.75, countInRange(2.0, 4.0) = 2

### Задача 5
„Мини toolkit за масиви“ с шаблонни функции

Напишете 4 шаблонни функции, за да има разнообразие от различни типове операции

- findIndex - Намира индекса на дадена стойност в масива. Връща -1, ако липсва.

- replaceAll - Заменя всички срещания на стойност oldValue с newValue и връща броя на замените.

- isSortedAscending - Проверява дали масивът е сортиран във възходящ ред (true/false).

- sumAtEvenIndices - Връща сумата на елементите на четни индекси: 0, 2, 4, ...

Изисквания:
- Само шаблонни функции, без класове и без std::vector.
- Да работят с обикновени масиви + подаден размер.
- Да има тестове поне с int и char.
- Да се обработи празен масив коректно.

Примерни тестове:
1. int arr = {4, 2, 4, 1, 7}
- findIndex(4) -> 0
- replaceAll(4, 9) -> 2 и масивът става {9, 2, 9, 1, 7}
- isSortedAscending -> false
- sumAtEvenIndices -> 7 + 2 + 1 = 10

2. char arr = {'b', 'c', 'a', 'c'}
- findIndex('a') -> 2
- replaceAll('c', 'z') -> 2
- isSortedAscending -> според ASCII сравнение

Бонус:
- Добави шаблонна функция printArray.
- Напиши един общ тест, който извиква всички функции последователно върху един и същ масив.
