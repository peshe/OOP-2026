## Битови полета
Битовите полета (bit fields) са специална възможност в езика C и C++, която позволява да се дефинират структури, в които определени член-данни заемат точно определен брой битове, а не цял байт или повече. Това е полезно за оптимизиране на паметта, когато трябва да съхраняваш много булеви или малки числови стойности.
Как работят битовите полета?
Вместо стандартното:
```cpp
struct Example {
    unsigned int flag1;
    unsigned int flag2;
};
```

можеш да напишем:
```cpp
struct Example {
    unsigned int flag1 : 1; // 1 бит
    unsigned int flag2 : 1; // 1 бит
};
```

Така и двете променливи ще заемат общо 2 бита, а не 2 цели числа (8 или 16 байта).
Синтаксис:
```cpp
struct StructName {
    тип име : брой_битове;
    // ...
};
```

- тип — обикновено unsigned int или int
- име — име на полето
- брой_битове — колко бита ще заема това поле

Защо се използват?
 - Пестят памет — особено когато имаш много флагове/булеви стойности.
 - Улесняват работата с хардуер — често се използват при програмиране на микроконтролери и драйвери, където всеки бит има специфично значение.

Ограничения
 - Не можеш да вземеш адрес на битово поле (& не работи).
 - Подредбата на битовете може да зависи от компилатора.
 - Не е подходящо за преносим код, ако трябва да обменяш данни между различни машини.

Създайте програма, която управлява потребители в компютърна система. Всеки потребител има различни права за достъп, които се пазят като битови полета в структура.

Изисквания:

3. Извеждане на информация:
   - Изведете списък с всички потребители и техните права в четим вид (например: "Read: Yes, Write: No, Execute: Yes, Admin: No").

4. Допълнително (по желание):
   - Изведете всички администратори.

3. Извеждане на информация:
    - Изведете всички сензори и техните настройки в четим вид (например: "Включен: Да, Аларма: Не, Безжичен: Да, Чувствителност: Висока").

4. Допълнително (по желание):
    - Изведете всички сензори, които са включени и имат максимална чувствителност.
