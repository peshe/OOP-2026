### Двоични файлове

В C++ двоичен файл е файл, в който данните се записват като „сурови“ байтове, а не като четим текст.

Текстов файл: числото 123 се пази като символи '1' '2' '3'.
Двоичен файл: числото се пази в паметния си формат (напр. 4 байта за int).

#### Предимства:
- по-бързо четене/писане;
- по-малък размер;
- подходящ за структури, изображения, аудио и др.

#### Недостатъци:
- не е човешки четим;
- възможни проблеми между платформи (размер на типове, padding).

В C++ се работи с std::fstream и флага std::ios::binary, например:
- запис: ofstream out("data.bin", ios::binary);
- четене: ifstream in("data.bin", ios::binary);
- Често се използват write() и read() за запис/четене на байтове.


Kакво правят write() и read()
- write() записва точно N байта в двоичен файл.
- read() чете точно N байта от двоичен файл.
- Те не форматират данните като текст, а работят директно с байтове.

Сигнатури
- ostream::write(const char* buffer, streamsize count)
- istream::read(char* buffer, streamsize count)
- buffer е адрес към паметта
- count е брой байтове, не брой елементи

Типичен начин на ползване
- За единична променлива: подаваш адреса ѝ и sizeof(тип)
- За масив: подаваш адреса на първия елемент и размер в байтове
- Обикновено за запис/четене на числа и структури се прави cast към char* / const char*

Проверка за грешки
- good() → всичко е наред
- fail() → логическа грешка при операция
- bad() → сериозна I/O грешка
- eof() → стигнат е край на файла

Кратък пример:
```cpp
#include <fstream>
#include <iostream>
#include <cstdint>

struct Person {
    std::uint32_t id;
    double score;
};

int main() {
    Person outData{42, 98.5};

    // Запис
    std::ofstream out("person.bin", std::ios::binary);
    out.write(reinterpret_cast<const char*>(&outData), sizeof(outData));
    out.close();

    // Четене
    Person inData{};
    std::ifstream in("person.bin", std::ios::binary);
    in.read(reinterpret_cast<char*>(&inData), sizeof(inData));
    in.close();

    std::cout << "id = " << inData.id << ", score = " << inData.score << '\n';
    return 0;
}
```
