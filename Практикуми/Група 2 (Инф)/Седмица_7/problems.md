### Задача 1

Реализирай клас SafeArray, който представлява динамичен масив от int.

#### Изисквания
1. Класът да има:
- поле size_t size
- поле int* data
2. Конструктори и деструктор:
   - Конструктор по подразбиране: създава празен масив (size = 0, data = nullptr)
   - Конструктор с параметър size_t n:
     - ако n == 0, създава празен масив
     - ако n > 1'000'000, хвърля std::invalid_argument
     - заделя динамична памет и инициализира всички елементи с 0

   - Копиращ конструктор (deep copy)
   - Деструктор (освобождава паметта)
3. Оператори/методи:
 - int& at(size_t index) и const int& at(size_t index) const
 - при невалиден индекс хвърля std::out_of_range
 - size_t getSize() const
 - void fill(int value) – запълва всички елементи
 - void print() const – отпечатва масива

4. Инициализация:
 - Използвай инициализиращ списък във всички конструктори
 - Не оставяй неинициализирани член-данни
5. Изключения и безопасност:
 - Покажи коректно прихващане на изключения в main() с поне два catch блока:
   - std::invalid_argument
   - std::out_of_range

#### Какво да демонстрира main()
1. Създаване на няколко обекта (default, с размер, копие)
2. Достъп до валиден и невалиден индекс (за да се види хвърляне на изключение)
3. Край на обхват (scope), за да се види кога се извикват деструктори
  - (можеш да добавиш диагностични std::cout в конструктори/деструктор)

### Задача 2
Реализирайте клас BankAccount, който моделира банкова сметка и демонстрира:
- жизнен цикъл на обектите
- конструктори и деструктор
- инициализация
- работа с изключения
- коректно управление на динамична памет

#### Условие

Създайте клас BankAccount със следните изисквания:

1. Полета:
- char* owner (динамичен C-низ)
- double balance
- unsigned id
- статично поле nextId за генериране на уникални ID-та

2. Конструктори и деструктор:
- Конструктор по подразбиране:
  - owner = "Unknown" (заделя динамична памет и копира текста)
  - balance = 0.0
  - задава уникално id
- Конструктор с параметри (const char* ownerName, double initialBalance):
  - ако ownerName е nullptr или празен низ, хвърля std::invalid_argument
  - ако initialBalance < 0, хвърля std::invalid_argument
  - заделя динамична памет за owner и копира текста
  - задава уникално id
- Копиращ конструктор:
  - deep copy на owner
  - копира balance
  - задава ново уникално id (копието е нова сметка)

- Оператор за присвояване:
  - защита при самоприсвояване
  - deep copy на owner
  - id на целевия обект не се променя

- Деструктор:
  - освобождава заделената памет за owner
  - отпечатва диагностично съобщение

3. Методи:
 - void deposit(double amount)
   - ако amount <= 0, хвърля std::invalid_argument
 - void withdraw(double amount)
   - ако amount <= 0, хвърля std::invalid_argument
   - ако amount > balance, хвърля std::runtime_error
 - const char* getOwner() const
 - double getBalance() const
 - unsigned getId() const
 - void setOwner(const char* newOwner)
   - ако newOwner е nullptr или празен низ, хвърля std::invalid_argument
   - подменя owner с нов deep copy
 - void print() const

4. Инициализация и безопасност:
- Не допускайте изтичане на памет.
- Не допускайте double delete.
- При изключение обектът да остава в валидно състояние.
- Не използвайте std::string за owner.

5. Изключения:
- В main() прихванете поне:
  - std::invalid_argument
  - std::runtime_error

#### Какво да демонстрира main()
1. Създаване на валидни обекти и извикване на print().
2. Успешни операции deposit и withdraw.
3. Невалидни операции:
- внасяне на невалидна сума
- теглене над наличния баланс
- задаване на невалидно име

4. Копиране и присвояване:
- създайте копие и покажете, че owner е deep copy
- направете присвояване и покажете, че id на целевия обект не се променя
5. Вложен scope, за да се видят извикванията на деструкторите.
