## Напишете следните шаблони на класове

### Pair<T, U>
Представлява двойка елементи. Елементите могат да са от еднакъв или различен тип.

- default + parametrized ctor
- getters + setters

Примери:
```cpp
Pair<int, int> coords(20, 30);
Pair<const char*, double> data("volume", 95); 
```

### Optional<T>
Представлява контейнер, който или позволява или не позволява достъп до елемента, който съдържа. 

Ако достъпът е позволен, това означава че със сигурност елементът е валиден. Ако достъпът не е позволен, се подразбира че той не е във валидно състояние.

- default + parametrized ctor
- get -> връща елемента ако е позволено, хвърля грешка в противен случай
- operator= -> копиращ (копира един Optional<T> в друг)
- operator= -> присвоява елемент от тип T; след него се подразбира че има достъп до елемента
- release -> връща елемента ако е позволено, хвърля грешка в противен случай И забранява повторен достъп до него след това.
- operator* -> еквивалент на get

Примери:
```cpp
Optional<int> integer = 1;
std::cout << *integer; // 1
std::cout << integer.get(); // 1

int a = integer.release(); // now a=1, but the value of "integer" can no longer be accessed
integer = 2;
std::cout << *integer; // 2
```

### Vector<T>

Представлява контейнер на масив от данни от определен тип. Този контейнер трябва да се преоразмерява динамично с добавянето на нови елементи, като се предпочита да има предвиден капацитет за да се избегне динамичното заделяне на памет при всяко добавяне на нови елементи.

- RO3
- operator+= / append - добавяне на елемент
- operator+= / addRange - добавяне на много елементи наведнъж
- operator-= / remove - премахване на всички срещания на елемент (по сравнение); NB: трябва да се запази редът на елементите и да няма "празни" места между тях
- operator[] - индексиране
- size/capacity - достъп до размера/капацитета
- БОНУС: overload на operator-=/remove, който приема функция за сравнение

Примери:
```cpp
Vector<int> ints;
ints += 1;
ints += 2;
ints += 3;
ints += 2;
ints += 100;

ints.remove(2);

std::cout << ints[0]; // 1
std::cout << ints[1]; // 3

for (int i = 0; i < ints.size(); i++)
    std::cout << ints[i] << ' '; // 1 3 100 
```
